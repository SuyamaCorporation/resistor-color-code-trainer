# Resistor Color Code Training Tool

## 概要
4バンド/5バンドモード切替で各バンドのカラーを選択すると抵抗値と許容差を即座に表示し、逆引きとクイズモードも備えた電子工作学習ツール。

## 機能
- 4バンド/5バンドモード切替
- バンドカラー選択（色分けドロップダウン）→ 抵抗値リアルタイム表示
- canvasによる抵抗器の視覚的描画
- 逆引き（値を入力→色バンド表示）
- クイズモード（ランダム配色→4択回答）
- カラーコード早見表

## 使い方
「Read Bands」モードでバンドの色を選択すると抵抗値が表示されます。「Reverse Lookup」では値を入力して対応する色バンドを確認できます。「Quiz Mode」ではランダムな抵抗器の値を4択で当てる練習ができます。
